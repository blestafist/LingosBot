## LingosBot 2.2.0 — WebUI administration

- **User activity:** administrators can see account creation dates, the most recent lesson run (start, finish, status and manual or scheduled source), and the next automatic run. Lingos credentials, workspace password hashes, and raw worker logs are not exposed.
- **Registration requests:** pending requests now appear on the administrator's Dashboard without a manual refresh. Open **Users → Registration requests** to approve or reject them.
- **Telegram alerts:** with a bot configured, each administrator can opt in under **Account → Telegram → Registration request notifications**. Alerts cover new approval-mode requests only and do not include applicant details.

### Upgrade notes

Back up the WebUI data directory and keep the existing encryption key before upgrading. The WebUI automatically adds the Telegram preference and notification queue to its database. Registration mode and existing accounts are unchanged. Registration alerts are off by default, independent of lesson notifications, and do not replay existing requests.
