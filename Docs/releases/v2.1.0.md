## LingosBot 2.1 — self-service registration for the WebUI

### New

- **Registration modes:** administrators choose how new accounts appear: `admin_only` (default, same as before), `approval` or `open`. Sign-up is available at `/register`, with rate limiting and duplicate-email protection.
- **Approval queue:** in `approval` mode new users wait as pending. Administrators approve or reject requests in the Users list. Pending users cannot see any data or start runs until approved.

### Fixes

- Telegram notifications are now sent only for regular lesson runs, not for other run modes (e.g. vocabulary collection). Stale queued notifications for those runs are removed on upgrade.
- Telegram bot and WebUI interface polish (layout, theme handling).

### Upgrade notes

- The database migrates automatically; registration stays `admin_only` until you change it.
- Pending approval also invalidates the user's sessions on approve.
