## LingosBot 2.2.2 — simpler WebUI telemetry

- **Users:** the collapsed **Activity & lesson plan** panel now highlights recent activity, lesson defaults and actual per-class lesson counts. A zero override skips the class.
- **Deployment:** admin telemetry is off by default and no longer has an in-app switch. Set `ADMIN_TELEMETRY=1` in `.env` and recreate WebUI to enable it. Existing in-app settings do not carry over. User data and schedules are unchanged.
- **CI:** regular Go tests and `go vet` still run; the Go race detector no longer runs on every build.

Use `ghcr.io/blestafist/lingosbot-webui:v2.2.2` for AMD64 or ARM64. See the [WebUI deployment guide](../webui/README.md#update-or-roll-back-a-running-server) for update and rollback steps.
