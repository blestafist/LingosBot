## LingosBot 2.2.1 — WebUI activity and deployment

- **Users:** a folded **Activity & lesson plan** panel shows synced classes, the latest lesson and run, totals from successful LingosBot runs, the next scheduled run and a safe summary of lesson settings. **Instance settings** can turn off admin access to this telemetry without changing users’ data or schedules.
- **Dashboard:** administrators can see the actual worker version selected at startup.
- **Sign-in:** new WebUI sessions last 30 days instead of 12 hours. Existing sessions keep their current expiry.
- **Docker:** GitHub Actions builds the WebUI and worker into a single versioned image for Linux AMD64 and ARM64: `ghcr.io/blestafist/lingosbot-webui:v2.2.1`.

Back up SQLite and keep the existing encryption key and data volume. See [the WebUI deployment guide](../webui/README.md#update-or-roll-back-a-running-server) for the Compose update and rollback steps.
